# README images

These are captures of Switch Magic 0.2.2's actual QML interface, rendered in
an isolated Quickshell session with fictional window titles and sample preview
content. They contain no personal desktop captures. The “Midnight gallery”
view exists only in the screenshot session; it is not shipped as a default.

Layout images are 1440 × 900. Preferences images are 1100 × 850.
The light/dark wordmarks reuse the app's vector icon geometry.
